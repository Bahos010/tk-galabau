# TK GaLaBau – Website

Offizielle Website von **TK GaLaBau**, Ihrem Fachbetrieb für Garten- und Landschaftsbau in Hilden.

## Live

👉 [https://bahos010.github.io/tk-galabau](https://bahos010.github.io/tk-galabau)

## Über das Projekt

Statische HTML/CSS/JS-Website für GitHub Pages, erstellt mit modernem, responsivem Design.

## Struktur

```
├── index.html
├── css/
│   └── style.css
├── js/
│   └── main.js
└── README.md
```

## Deployment

```bash
git add .
git commit -m "Initial commit"
git push -u origin main
```

GitHub Pages muss im Repository unter **Settings → Pages → Source: Deploy from branch `main` / root** aktiviert werden.
